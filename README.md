# Patch Bandit — Ideas

This repository holds no code. It is the stash where Snick and the Patch Bandit crew collect, sort, and debate ideas for **free online tools** using GitHub Discussions.

## What makes a good idea

A good idea is a simple job someone currently charges rent for that a browser could do on your own device for free.

Think:
- A monthly fee or trial trap wrapped around a single button
- A basic utility locked behind an account, a login wall, or a watermark
- A small task that uploads your files to a server while trackers watch

## How to pitch an idea

1. Open the [Discussions](https://github.com/patch-bandit/ideas/discussions) tab.
2. Start a new discussion in the **Ideas** category.
3. Fill out the three short fields: the idea, what it replaces or who charges for it now, and who it would help.

No code or mockups required. Plain English beats a fancy spec at 3 AM.

## How we pick what hits the bench

We move ideas from the stash to the bench one at a time. We look for tools that:
- Do one small job cleanly in a browser tab with zero uploads
- Need no sign-up, no database, and no tracking
- Save real people from an annoying fee or lock-in
- Can ship small, honest, and MIT licensed

An idea in the stash is a candidate with no promise and no deadline. When one moves to the bench or ships, we say so publicly.

## Everything here is public

Every discussion posted in this repository is public. Anyone can read it, suggest a simpler way to build it, or grab an idea and run with it. Do not post private data, secrets, or anything you want kept under wraps.
